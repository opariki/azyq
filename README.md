# AZYQ — Smart Pantry

Приложение для учёта домашних продуктов: сроки годности, список покупок, статистика списаний. Интерфейс на русском, казахском и английском.

## Запуск
```bash
npm start      # http://localhost:3000 (Node 18+, зависимостей нет)
npm test       # 21 автотест: модель, сервер, переводы
```
Без сервера (все файлы лежат в корне проекта) данные хранятся в `localStorage`.

## Структура
| Файл | Роль |
|---|---|
| `model.js` | Типы (JSDoc), валидация, быстрые шаблоны, даты — общий код для браузера и сервера |
| `store.js` | Хранилище: API `/api/state`, запасной вариант — localStorage, миграция данных v1 |
| `i18n.js` | Переводы RU / KZ / EN |
| `main.js` | Интерфейс |
| `server.js` | Мини-бэкенд: `GET/PUT /api/state`, данные в `data/state.json`, защита от выхода за пределы папки |

## Что умеет
- Статусы «сегодня / завтра / N дней / просрочено», сортировка по сроку
- Напоминания: баннер о продуктах, которые скоро испортятся, и уведомление браузера раз в день
- Быстрое добавление: шаблоны с категорией, единицей и сроком
- Статистика: использовано / списано

## Семья (общие данные на всех устройствах)
Кнопка «Семья» в шапке: один человек создаёт семью и получает код вида `XXXX-XXXX`, остальные вводят его на своих устройствах. Данные хранятся в Supabase, синхронизируются каждые 5 секунд; при одновременном изменении побеждает первое сохранение, второе устройство получает свежие данные.
- `api/family.js` — серверная функция Vercel (создание, чтение, сохранение с проверкой версии). Ключ Supabase хранится только на сервере.
- `setup.sql` — таблица `families` (доступ из браузера закрыт, включён Row Level Security).
- Переменные окружения Vercel: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` (secret key `sb_secret_...`).
Без этих настроек сайт работает как раньше, данные хранятся в браузере.

## Деплой
**Vercel (статический режим):** импортировать репозиторий, Framework — Other, Build Command пустой. Данные будут в браузере пользователя.
**Render / Railway / Fly.io (с бэкендом):** Start Command `npm start`. Для постоянного хранения подключить диск (Render Disk) — на Vercel файловая запись не сохраняется.
